Deterministic visual engineering for AI agents

FastSVG

Language models guess coordinates. FastSVG computes them. A typed, modular engine that turns intent into measured geometry, perceptual color, timed motion and real APNG frames — renderable, diffable, deterministic.

01Why FastSVG

001

Prediction → computation

Bezier extrema, arc length, WCAG contrast and loop seams are solved with math, not sampled from a model's imagination.

002

Scene IR, not string soup

Every node has an identity, a parent, a provenance. Edits are atomic patches — undoable, targetable, reviewable.

003

Color you can trust

sRGB ↔ linear ↔ OKLab/OKLCH with hue-locked tone scales and ΔE-continuous gradients. Banding is measured, not vibes.

004

Motion as a first-class engine

Timelines, keyframes, cubic-bezier solved by Newton–Raphson, analytic damped springs, loop-seam detection.

005

Real APNG, zero deps

A PNG/APNG encoder and decoder written from scratch: CRC-checked chunks, fcTL/fdAT sequencing, alpha preserved.

006

Render → diff → repair

Deterministic frame rendering feeds a pixel-diff engine with changed-region bounding boxes. Quality is a measurement.

02Install & use

# clone & verify (node ≥ 20)
git clone https://github.com/Syron01/fastsvg && cd fastsvg
npm install
npm test                        # 77/77 green

# CLI: measure a path
npx tsx apps/cli/src/main.ts validate path.d
# → Geçerli path — 4 segment, bounds: {"minX":10,"minY":10,"maxX":50,"maxY":40}

# CLI: scene → SVG / PNG, image compare
npx tsx apps/cli/src/main.ts export scene.json --out out.svg
npx tsx apps/cli/src/main.ts render scene.json --out out.png
npx tsx apps/cli/src/main.ts compare a.png b.png --tolerance 2

03Wire it to your model (MCP)

// claude_desktop_config.json — 10 tools, stdio transport
{
  "mcpServers": {
    "fastsvg": { "command": "npx", "args": ["fastsvg-mcp"] }
  }
}
