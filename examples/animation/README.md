# Örnek: hareketli kutu animasyonu (scene + timeline → APNG)

Bu örnek `renderTimelineApng`'nin uçtan uca kullanımını gösterir.

```bash
npx tsx examples/animation/run.ts
# çıktı: examples/animation/box.apng
```

Kod `run.ts` içinde: 32×32 sahne, kırmızı kutu, 500ms'de 20px sağa hareket, 10 fps → 5 kareli APNG.
